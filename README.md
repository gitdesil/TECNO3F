## Descripción

Este proyecto fue desarrollado como Trabajo Integrador del curso de Introducciòn a python en Tecno3F.



Contiene dos aplicaciones desarrolladas en consola:


### 1. Sistema de Tickets
Permite gestionar tickets de soporte.
## Funciones disponibles:
* Alta de ticket.
* Lectura de tickets mediante su número.
* Almacenamiento de cada ticket en un archivo de texto.
* Generación automática de un número de ticket aleatorio.


### 2. Ta-Te-Ti
Juego para dos jugadores desde la terminal.
## Características:
* Tablero de 3x3.
* Alternancia de turnos entre los jugadores.
* Validación de movimientos.
* Detección de ganador o empate.
* Interfaz por consola con colores.

## Requisitos: Python 3
## Ejecución
Desde la carpeta del proyecto ejecutar:
 main.py
## Desde el menú principal se puede elegir entre:
1. Sistema de Tickets.
2. Juego Ta-Te-Ti.
3. Salir del programa.
